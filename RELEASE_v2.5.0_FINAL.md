## 🚀 Upload Instructions

### Step 1: Access Play Console
1. Go to: https://play.google.com/console
2. Sign in with your developer account
3. Select "Mavrixfy" app (or create new app if first release)

### Step 2: Create New Release
1. Navigate to: **Production** → **Releases**
2. Click: **Create new release**
3. Click: **Upload** button

### Step 3: Upload AAB
1. Select file: `android/app/build/outputs/bundle/release/app-release.aab`
2. Wait for upload to complete (may take 2-5 minutes)
3. Wait for Google Play to process the bundle

### Step 4: Enter Release Details
**Release Name:**
```
Mavrixfy v2.5.0 - Stable Release
```

**Release Notes (copy from above):**
- Use the "Short Version" for the summary field
- Use the "Full Version" for the detailed release notes field

### Step 5: Review and Rollout
1. Review all information
2. Set rollout percentage (recommend 100% for stable release)
3. Click **Review release**
4. Click **Start rollout to Production**
